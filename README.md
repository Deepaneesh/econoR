# econoR

**econoR** is an R package for organizing and managing economic indicators by maintaining relationships between **actual and calculated data**.

It helps to:

- Store actual and calculated data separately
- Maintain relationships between economic indicators
- Ensure consistent econometric relationships
- Easily retrieve and reuse calculated data
- Improve data traceability and consistency

The goal of **econoR** is to make economic data **structured, traceable, reusable, and economically consistent**.
